Ana Prompt

Teknik gereksinimler:
- HTML5 Canvas API, harici kütüphane yok
- Arka plan: koyu (#080c10) + ince grid çizgileri (rgba(255,255,255,0.02), 60px)
- Karakter: yuvarlak kuş, radius 14px, göz detayı
- Yerçekimi: 0.4px/s², zıplama: -7px
- Borular: 52px genişlik, 160px gap, 2px/frame hız
- State machine: IDLE → PLAYING → GAMEOVER
- Click to start, game over ekranı, tekrar dene butonu
- High score (JS değişkeninde, localStorage yok)
- Sağ alt köşede araç imzası
